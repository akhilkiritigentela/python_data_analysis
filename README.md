# Python Data Analysis and Visualisation

A collection of Python notebooks exploring numerical computing, tabular data analysis, exploratory data analysis and data visualisation.

- **NumPy:** numerical computing and array operations
- **Pandas:** working with tabular datasets, data cleaning and transformation
- **Exploratory data analysis:** inspecting datasets and identifying patterns
- **Visualisation:** creating plots using Matplotlib and Seaborn
